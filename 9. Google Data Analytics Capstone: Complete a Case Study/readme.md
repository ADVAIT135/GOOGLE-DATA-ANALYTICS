# 🚴 Cyclistic Case Study – Data Analytics Project
## 📌 Project Overview
Cyclistic, a bike‑share company, wants to convert casual riders into annual members to increase revenue and customer loyalty.
This case study analyzes 12 months of trip data (5.5M+ rides) to uncover behavioral differences between rider types and provide actionable recommendations.

### 📂 Dataset
- Source: Monthly .csv files (Jan–Dec 2025).
- Size: ~5.5M rows, 12 files.
- Key fields: ride_id, started_at, ended_at, member_casual, start_station_name, end_station_name.

### 🛠 Tools & Libraries
- Python: Pandas, NumPy, Matplotlib, Seaborn
- Data Cleaning: Missing values, duplicates, outlier removal (>24 hrs)
- Transformation: Derived fields (ride length, day of week, month)
- Visualization: Charts for ride length, frequency, seasonal trends, station usage

### 🔎 Analysis Highlights
- Ride Length: Casual riders average 20–25 min, members 12–14 min.
- Day of Week: Members ride more on weekdays (commuting), casual riders peak on weekends (leisure).
- Seasonal Trends: Casual rider activity spikes in summer months, members remain steady year‑round.
- Station Usage: Casual riders favor tourist areas/parks, members prefer business districts/residential zones.

### 📊 Visualizations
- Bar chart: Average ride length by rider type
- Line chart: Ride counts by weekday vs weekend
- Line chart: Monthly ride counts (seasonal trends)
- Bar chart: Top start stations by rider type

### ✅ Recommendations
- Target casual riders with membership incentives (summer promotions, weekend discounts).
- Highlight commuter benefits (cost savings, convenience, employer partnerships).
- Leisure campaigns around parks/tourist areas to capture weekend riders.
- Digital outreach via app notifications, email, and social media.
