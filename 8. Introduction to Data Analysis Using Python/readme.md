# Introduction to Data Analysis Using Python

This folder contains notebooks and activities for "Introduction to Data Analysis Using Python" — a hands-on module that covers core Python concepts and how to use NumPy and pandas for basic data analysis tasks. The materials are suitable for beginners and for use in guided labs or self-study.

## Contents

Notebooks and activities included in this folder:
- `Activity_Use Python syntax.ipynb` — Python syntax fundamentals and setup
- `Activity_Strings.ipynb` — Working with strings
- `Activity_Lists & tuples.ipynb` — Lists and tuples basics
- `Activity_Dictionaries & sets.ipynb` — Dictionaries and sets
- `Activity_For loops.ipynb` — For loops and iteration patterns
- `Activity_While loops.ipynb` — While loops and loop control
- `Activity_Conditional statements.ipynb` — If/elif/else and decision making
- `Activity_Functions.ipynb` — Writing and using functions
- `Activity_Dataframes with pandas.ipynb` — Intro to pandas DataFrame operations
- `Activity_Arrays and vectors with NumPy.ipynb` — NumPy arrays and vectorized operations
- `Annotated follow-along guide_Functions and conditional statements.ipynb` — Guided walkthrough for functions & conditionals


## Prerequisites

- Python 3.8+ recommended
- Jupyter Notebook or JupyterLab (or use Google Colab)
- Recommended Python packages:
  - numpy
  - pandas
  - matplotlib (optional, for plotting)
  - seaborn (optional)

You can install the basics with:
```
pip install numpy pandas jupyter
```

## How to open and run the notebooks

Option 1 — Run locally
1. Clone the repository:
   ```
   git clone https://github.com/ADVAIT135/GOOGLE-DATA-ANALYTICS.git
   ```
2. Change into the folder and launch Jupyter:
   ```
   cd "8. Introduction to Data Analysis Using Python"
   jupyter lab
   ```
3. Open a notebook and run cells in order.

Option 2 — Open in Google Colab
- To open a notebook in Colab, use the URL pattern:
  `https://colab.research.google.com/github/ADVAIT135/GOOGLE-DATA-ANALYTICS/blob/697be070efe0dace953f19735700e0d5fa0f0d4b/8.%20Introduction%20to%20Data%20Analysis%20Using%20Python/<NOTEBOOK_FILENAME>.ipynb`
